# Архів

Історичні матеріали, перенесені 11.10.2026. Сервер їх не завантажує; поточний код сторінок розташований у `public/`, каталог активних ігор — `games/index.json`.

## `legacy-root/`

Колишні кореневі `host.html`, `play.html`, `screen.html`, `index.html`, `seasons.html`, `style.css`, `common.js`, `kinohardkor.json`, `index.json`. Це старі версії, які відрізняються від активних файлів. HTML збережено для читання; відносні посилання після переміщення можуть не працювати.

## `games/`

Колишні `games/back_to_2000s.draft.json`, `games/back_to_2000s_round2_approved.draft.json` та `games/media_test.json`. Вони не входили в каталог ігор. Чернетки збережені як редакторські матеріали, тестова гра — як приклад медіапитань.

Усі п'ять ігор із поточного індексу залишено на місці. Кореневий `questions.json` також залишено: його використовує старий HTTP-маршрут `/questions.json`.

Кореневий файл `download` видалено як точну копію `.gitignore`; сам `.gitignore` залишено.
